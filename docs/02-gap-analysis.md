# NWUCHAS-CMIS gap analysis

| PRD domain | Current state | Required deliverable |
|---|---|---|
| Dedicated foundation | Do not reuse | Eliminate SaaS provisioning; model campus/school/department/programme. |
| RBAC/audit | Partial | Server-scoped permissions, MFA and immutable high-risk audit. |
| Admissions | Partial UI/fixtures | Applicant, evidence, eligibility, committee decision, offer and enrolment. |
| Student registry | Partial | Immutable key and independent academic/finance/indexing/clinical states. |
| Academics/exams | Partial school model | Curriculum version, semesters/modules, moderation and versioned corrections. |
| Clinical/regulators | Absent | De-identified logbooks, placements, supervisor validation and evidence. |
| Student finance | Partial | Double-entry posting, periods, refunds and reconciliation. |
| Payments | Absent | Intents, signed webhook inbox, verification and settlements. |
| HR/payroll | Partial directory | Contracts, effective-dated rules, approval, lock, exports and evidence. |
| Operations/security | Partial | Secret scanning, backup restore, monitoring and CI gates. |

No statutory rate, fee, API credential, programme, accreditation or operational record is treated as validated.
