# Changelog — EduSphere SMIS
All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-16
### Initial Baseline Production Release
- **Platform Foundation (Phase 0 & 1):** Multi-tenant school organization provisioning, multi-campus scoping, subscription tier governance (Community Starter to Enterprise Group), and RBAC security model.
- **Student Information System (Phase 2):** Admissions pipeline, unique student number issuing (`EDS-2026-XXXX`), verified guardian linking, and longitudinal learner profile.
- **Academic Management & Assessment (Phase 3):** Configurable curriculum schemes, continuous assessment (40%) and examination (60%) markbooks, ECE qualitative developmental milestones, moderation approval pipeline (Draft &rarr; Moderated &rarr; Approved &rarr; Published), and official branded PDF report card generator.
- **Student Attendance (Phase 3):** Daily class register taking, lateness tracking, offline sync queue simulation, and automatic reconciliation.
- **Fees & Financial Ledger (Phase 4):** Itemized fee schedules, term invoicing with idempotency protection, payment recording across cash, bank, and mobile money, sequential numbered receipts, and double-entry immutable financial posting journal.
- **Parent & Guardian Portal (Phase 4):** Mobile-first responsive interface with child switcher, published report card views, attendance summaries, and simulated online mobile money checkout.
- **Staff & HR Registry (Phase 7):** Educator directory with qualifications and Teaching Council of Zambia (TCZ) registration number and practising certificate expiry alerts.
- **Automated Validation:** Automated test suite covering AC-01 through AC-09 (Tenant isolation, guardian access revocation, financial reversals, offline sync, ECE milestone assessment).
